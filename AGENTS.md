# Reglas para el Agente (AGENTS.md)

Este archivo contiene las reglas y principios dictados por el usuario para el desarrollo de este proyecto de aprendizaje.

---

## Reglas Principales

### 1. Aplicación de Aprendizaje (Paso a Paso)
- No adelantarse ni anticiparse demasiado con arquitecturas complejas o patrones avanzados.
- Mantener las soluciones simples, directas y explicadas de forma didáctica.

### 2. Documentación Constante en Código
- **Cada acción, cambio o adición** realizada en el código debe estar debidamente documentada mediante comentarios en el archivo correspondiente (KDoc, comentarios inline o comentarios XML).

### 3. Registro de Reglas
- Cualquier nueva regla o instrucción dada por el usuario debe registrarse e integrarse en este archivo `AGENTS.md`.
